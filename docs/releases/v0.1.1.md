Sessions can now carry a tag, so an app that loses a session id gets its
session back instead of starting another one.

- `session.create` takes a tag. The oldest live session the same client
  made with that tag is reused, and that client's other sessions of the tag
  end.
- `session.reconcile` ends a client's tagged sessions whose tag it no longer
  keeps. Untagged sessions and other clients' sessions are untouched.
- `osewa local ls|kill|reconcile` does the same on the host without the
  server.
- The C API gains `osewa_open_options.tag` and `osewa_reconcile`.
- Android apps can embed osewa: `scripts/build-android-lib.sh` builds
  `libosewa.so` per ABI.
- `Osewa.xcframework` is smaller: the device slice goes from 5.28 MB to
  about 3.39 MB.

This release interoperates with v0.1.0 (`p0-s1`).
