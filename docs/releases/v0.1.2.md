osewa no longer installs updates on its own unless you ask it to, and it can
reach a host behind a bastion.

- **Updates ask by default.** osewa now only says when a release is out;
  `osewa update` installs it, and `osewa set auto-update auto` turns automatic
  installs back on. A saved setting stays as it is, so only installs with no
  setting change. Older builds still on the old default install this release
  by themselves, and it's the last one they install that way.
- **Hosts behind a bastion.** `osewa login --via-ssh` saves a host that
  connects through ssh, ProxyJump included, with pinned TLS end to end and
  nothing running on the bastion. A host behind a proxy falls back to this by
  itself if a direct dial fails. It needs a key or agent for every hop, and
  runs over WebSocket only.
- **Taking over works under Kitty keyboard modes.** A viewer's terminal no
  longer takes on the program's keyboard mode, so Ctrl-T and `~t` stay plain
  bytes. Only the owner's terminal follows the program.

This release interoperates with v0.1.1 (`p0-s1`).
