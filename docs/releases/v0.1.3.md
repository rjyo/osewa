Updates restart cleanly on Macs again, and redraws no longer scroll in from
the top.

- **Updates restart on macOS.** A server installed with `osewa service
  install` could install an update and then fail to restart into it ("has
  mode 744; it must be private (chmod 700)"): launchd had created
  `~/.local/state/osewa` for the server log with a mode that was too open.
  osewa now creates that folder private before launchd starts the server,
  and sets an existing one to 0700 instead of refusing it. Macs already in
  this state fix themselves when they update to this release, with no
  `chmod` needed. Linux was not affected.
- **Redraws appear at once.** A full redraw, which carries the scrollback, is
  now drawn as one synchronized update, so the terminal no longer shows the
  screen scrolling down from the top on every session switch.
- **`osewa_redraw_snapshot` for apps.** The C API can hand a new view the
  terminal as one Ghostty snapshot instead of VT, with the rest of the
  repaint sent as VT after it. It falls back to the VT redraw when the
  terminal can't be encoded.

This release interoperates with v0.1.2 (`p0-s1`).
