The first release of osewa: persistent remote terminals over QUIC, falling
back to TLS WebSocket where UDP is blocked.

- Sessions live on the host and survive roaming, sleep, dropped links and
  server restarts. The screen is kept by libghostty-vt.
- Port forwards and remote commands share the session's connection.
- `osewa login HOST` installs osewa on a host over ssh and pairs this
  device with it.
- osewa updates itself; `osewa set auto-update auto|ask|off` controls how.

Install on Linux or macOS (amd64, arm64):

    curl -fsSL https://osewa.dev/install.sh | sh

The macOS builds are signed with a Developer ID and notarized.
